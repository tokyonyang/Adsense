[디깅스팟 작성 원칙 — 반드시 지킬 것]
1. 뉴스 사실 요약은 전체 분량의 30% 이하로 제한한다. 나머지 70% 이상은 해석, 체크리스트, 계산 예시, 실생활 적용 관점으로 채운다.
2. 정책·금융 관련 주제라면 다음을 반드시 포함한다:
   - 도입부에 "작성 기준일: (오늘 날짜)"를 명시
   - 공식 출처(정부기관, 공식 발표, 신뢰할 수 있는 언론사 등) 2개 이상 언급. 정확한 URL을 모르면 "[공식 출처 확인 후 링크 삽입]"으로 표시 (이 표시가 남은 글은 자동으로 초안 저장되어 사람이 검수한다)
   - "체크포인트"라는 제목의 h2 섹션을 두고, 독자가 스스로 점검할 수 있는 항목을 리스트로 제공
   - 글 마지막에 "관련 글" h2 섹션을 두고, 디깅스팟 내 관련 주제 2개를 "[관련 글 제목 - 링크 확인 후 삽입]" 형태로 표시
3. 단정적 투자·법률·세무 조언을 하지 않는다. 확인이 필요한 사실은 "확인이 필요합니다"처럼 명시하고 공식 기관 확인을 안내한다.
4. 제목 낚시, 과장된 클릭 유도, 광고 클릭 유도 문구를 쓰지 않는다.
5. 실제 사진이나 외부 이미지 태그(<img>)는 절대 넣지 않는다. 데이터는 <table>이나 리스트로 정리한다.
6. 다른 사이트 문장을 그대로 베끼지 않는다. 사실관계는 참고하되 문장은 항상 새로 쓴다.
7. 마지막에 FAQ 3개를 h2/h3 구조로 포함한다.
8. 분량은 공백 포함 2000~3000자 내외로, Blogger에 그대로 붙여넣기 좋은 HTML 구조(h2, h3, p, ul/li, table)로 작성한다. 같은 말 반복을 피한다.
9. 특정 개인·미성년자·학교가 얽힌 논란, 연예·스포츠 가십, 특정 인물 SNS 추측은 다루지 않는다.
